# Landing for Looton – Second-Hand Platform

[**Looton**](https://looton.ru/) is a modern second-hand marketplace focused on making the process of discovering, browsing, and purchasing pre-owned items simple and visually engaging.

The landing was built as a dedicated frontend experience for the platform with a strong visual presentation.

**Design & frontend:** @pornoiya

## Features

- Responsive marketplace interface for desktop and mobile screens
- Clean and minimal visual language
- Frontend implementation based on the provided product design
- Development setup with a fast local development workflow

## Getting Started

Install the project dependencies:

```bash
yarn
```

Start the development server:

```bash
yarn dev
```

After starting the development server, the website will be available through the local development URL provided by the framework.
